## Markdown {#common-markdown}

Prose written in CommonMark, with GFM tables and fenced code blocks allowed. It can link to something in the project with a `dsds:` link, whose target is any string a `to` field accepts.

**Example:**

```yaml
statement: Do not use button when the action navigates to a new URL; use the link entry instead.
```
