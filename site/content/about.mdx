# About

DSDS is a schema for design system documentation. A document describes a design system's components, tokens, themes and patterns in one YAML file, so a person can read it as documentation and an agent can read it as ground truth. The specification, the JSON Schema and this site are open source under the Apache 2.0 license.

The project is maintained by [PJ Onori](https://pjonori.com) as a pre-1.0 project. It's still a draft. The schema has changed in breaking ways between releases, and it can change again before 1.0. Each release is recorded in the [changelog](https://github.com/somerandomdude/design-system-documentation-schema/blob/main/CHANGELOG), and the [stability](/stability) page says what can change and how much notice you get.

Many people have contributed to DSDS. The [overview](/) credits contributors by name. Their work covers agent skills, accessibility guidelines, metadata schemas, the rule catalog and the examples. Code, examples and schema changes come in as pull requests on [GitHub](https://github.com/somerandomdude), and the [contributing guide](https://github.com/somerandomdude/design-system-documentation-schema/blob/main/CONTRIBUTING.md) explains what a change needs.

If you're new, start with the [overview](/), then the [quick start](/quickstart). To ask a question or report a problem, see the [contact page](/contact).
